# Política de Privacidade — ConnectEaseDesktop

Última atualização: 14/10/2026

O ConnectEaseDesktop é um aplicativo de acesso remoto desenvolvido pela ION Sistemas, baseado no projeto de código aberto RustDesk.

## Dados tratados

- **Identificador do dispositivo (ID) e nome do dispositivo**: usados para que outros dispositivos encontrem este aparelho no servidor de conexão.
- **Endereço IP**: necessário para estabelecer a conexão entre os dispositivos.
- **Conteúdo da sessão remota** (tela, áudio, entradas de teclado/mouse, área de transferência e arquivos transferidos): trafega de forma criptografada entre os dispositivos conectados e **não é armazenado** pelos servidores da ION Sistemas.
- **Conta e catálogo de endereços** (somente se você fizer login): nome de usuário e lista de dispositivos salvos.

## Permissões no Android

- **Acessibilidade**: permite que o técnico controle a tela durante uma sessão autorizada por você. Nenhum dado é coletado por meio desse serviço fora de uma sessão ativa.
- **Captura de tela**: necessária para transmitir a tela durante a sessão.
- **Microfone**: usado apenas para transmitir o áudio do sistema/sessão, quando habilitado.
- **Armazenamento**: usado apenas para transferência de arquivos solicitada por você.

Toda sessão precisa ser aceita no dispositivo controlado ou autorizada com senha definida por você.

## Servidores

As conexões são intermediadas por servidores operados pela ION Sistemas. Os registros técnicos (ID, IP e horário de conexão) são mantidos apenas pelo tempo necessário à operação e segurança do serviço.

## Compartilhamento

Não vendemos nem compartilhamos dados pessoais com terceiros, exceto quando exigido por lei.
